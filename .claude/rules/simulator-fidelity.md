# Simulator Fidelity and Training Safety

Applies to all work in this repository: the simulator model, the user interface, training and
qualification content, and calibration data.

The trainer teaches people to operate a real 700 W amplifier. A simulator that behaves
plausibly but wrongly teaches wrong habits with confidence. These rules keep it honest.

## Every physical value has a source

Every number the model uses has a recorded source, kept with the value in the code or data. The
number may be a capacitance, an inductance, a tube characteristic, a protection threshold, a
dial calibration, an antenna impedance or a cable loss. The source is one of:

| Source | Meaning |
|---|---|
| `manual` | ACOM 1010 User's Manual, cited by section, table or figure |
| `datasheet` | 4CX800A / GU74B tube data, cited by page |
| `measured` | Measured on the W3USR installation, cited by the data file and date |
| `derived` | Computed from other sourced values; name them |
| `placeholder` | Chosen to make the model run. Not real. To be replaced by calibration |

- **Placeholders are allowed and expected** in early versions. They are never presented as the
  real amplifier's values, in the interface or in documentation.
- **Do not invent component values and present them as ACOM's.** ACOM publishes only a
  simplified schematic (manual §5.5) without values. Pi-L network component values are
  placeholders until they are fitted to calibration data.
- The interface shows the model's calibration status (uncalibrated, partially calibrated or
  calibrated against a named data set), so a student knows how far to trust it.

## Calibration is a first-class path

- Calibration data (knob settings, power readings, antenna sweeps) lives in versioned data files,
  separate from the code, with who measured it, when, and with what instrument.
- Fitted parameters are regenerated by a committed script from committed data, never tuned by
  hand to look right.
- Antenna impedance data comes from the `w3usr_antennas` submodule. Antenna data belongs there,
  not here.

## The manual governs procedure

- The tuning procedure, preset table, protection behavior and operating cautions taught here
  follow the ACOM 1010 User's Manual. Cite the section.
- If the simulator's physics and the manual disagree, the manual's procedure is what is taught,
  and the disagreement is recorded as a model defect.
- Do not copy the manual into this repository. It is a third-party document carried by the
  `w3usr_antennas` submodule. Short quotations with citations are fine.

## The simulator does not authorize operation

- Passing a simulator qualification makes a student **eligible** for a supervised check-out on
  the real amplifier. The app never states or implies that it licenses or authorizes anyone to
  operate the station.
- Timed and game features never reward an unsafe action. Any run that would damage or trip the
  real amplifier, or that breaks a manual caution, is disqualified, not penalized.
- Physical safety content (lethal voltages inside the amplifier, RF exposure) stays accurate,
  and the app never suggests opening the amplifier.
